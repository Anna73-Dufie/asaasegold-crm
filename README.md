# AsaaseGold Cocoa CRM 🍫🇬🇭

A full CRM for **AsaaseGold Cocoa**, a fictional made-in-Ghana chocolate brand that buys beans from Ghanaian farmer cooperatives and turns them into chocolate at home.

**Live demo:** _add your Vercel link here_

## What's inside

- **10 dashboards:** Overview, Web analytics, Sales monitoring, Social media, Ad campaigns, Email marketing, Event management, Help desk, Finance, Channel growth
- **CRM:** Leads, Contacts, Accounts, Deals (kanban board), Proposals, Contracts, Invoices, Payments
- **Commerce:** Customers (with segments), Orders, Products
- **Apps:** Unified inbox (WhatsApp, Instagram, Facebook, TikTok, X, LinkedIn, email), Email, Tasks, Calendar
- **Ask Asaase AI:** a built-in assistant that answers questions from the CRM data
- **Farm to bar:** a map of the six cocoa cooperatives and what farmers were paid
- **Themes:** Orange, Chocolate, Yellow and black, Green and white

## The data

A synthetic dataset generated in Python (`generate_asaasegold_crm.py`) to mirror a real cocoa brand's CRM: **28 linked tables** from 1 January 2025 to 24 November 2026, including leads, deals, contracts, invoices, retail orders, daily social media, web, ads, email, events, help desk tickets, messages, expenses and cocoa sourcing.

- `data/`: every table as a CSV, ready for Power BI, SQL or Python
- `AsaaseGold_CRM_Dataset.xlsx`: all tables plus a live-formula summary dashboard

All names, companies and figures are fictional. Patterns are built in on purpose for analysis practice; they are not real-world measurements.

## Built with

HTML, CSS and JavaScript (single file, no frameworks), Python (pandas) for data generation, Excel.
